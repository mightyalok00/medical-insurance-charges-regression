# Fairness and Responsible Use

This project is an educational regression portfolio project, not an actuarial decision system.

Considerations:
- Sensitive or demographic variables can create fairness risks when used operationally.
- Predictive association does not establish causation.
- Performance should be reviewed across relevant subgroups before deployment.
- Real insurance use would require legal, actuarial, governance, temporal, and external validation.
- Predictions should not be used for eligibility or adverse-action decisions from this project alone.
