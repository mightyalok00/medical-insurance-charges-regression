# Model Card

## Purpose
Predict medical insurance charges for portfolio and educational analysis.

## Models
- Linear Regression
- Polynomial Regression
- Decision Tree Regression

## Final dashboard model
The tuned Decision Tree pipeline is used as the primary prediction model in the Streamlit app, while all three trained models are retained for comparison.

## Limitations
Predictions are not intended for real insurance pricing, eligibility, underwriting, or adverse-action decisions without external validation, fairness review, and domain governance.
