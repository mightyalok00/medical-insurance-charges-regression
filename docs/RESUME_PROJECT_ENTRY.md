## ATS-Friendly Project Title

**Medical Insurance Charges Regression | Python, scikit-learn, Streamlit**

## Resume Version — 4 Bullets

- Built and compared **Linear Regression, Polynomial Regression, and Decision Tree Regression** pipelines on **1,337 cleaned insurance records** using Python, pandas, scikit-learn, and leakage-safe preprocessing.
- Applied **5-fold cross-validation**, training-only model selection, and hyperparameter tuning; evaluated models using **MAE, MSE, RMSE, and R²** on an untouched holdout test set.
- Achieved **Test R² = 0.8972** and **Test RMSE = 4,345.88** with the tuned Decision Tree model, reducing RMSE by approximately **27% compared with the Linear Regression baseline**.
- Deployed a professional **Streamlit dashboard** with model selection, three-model prediction comparison, interactive filtering, business insights, feature importance, and downloadable data outputs.

## LinkedIn Project Description

Built an end-to-end machine learning regression project to predict medical insurance charges from age, sex, BMI, number of children, smoking status, and region. The project compares Linear Regression, Polynomial Regression, and Decision Tree Regression using leakage-safe preprocessing, 5-fold cross-validation, hyperparameter tuning, and an untouched holdout test set.

The tuned Decision Tree produced the strongest saved holdout results with **Test R² = 0.8972** and **Test RMSE = 4,345.88**, improving RMSE by approximately **27% versus the Linear Regression baseline**. The project also includes model interpretation, feature importance, business insights, saved model pipelines, reproducible reports, and a deployed Streamlit dashboard.
